DiskGOup shows you where your disk space went and gives you a staged, reviewed
cleanup flow instead of a one-click "delete my stuff".

**The CLI is the product.** The Electron desktop app is a thin front-end that
drives the CLI as a child process — if the GUI were deleted tomorrow, nothing
would be lost.

## How it works

```
diskgoup-alternative/
├── src/diskgoup/     Python CLI (uv project) — all the disk logic
├── electron/         Electron main process (TypeScript)
└── ui/               Vite + React renderer (TypeScript)
```

One scan powers every view: the walk is written into a persistent SQLite index,
and the tree, the treemap, the search, the duplicate finder and the reports all
read that same result set instead of touching the disk again.

Nothing is ever deleted straight away:

```
stage → review → validate → confirm → revalidate → recycle bin
```
